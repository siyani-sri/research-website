Project Overview

What is ScreenPilot?

ScreenPilot is an innovative AI system that observes screens using computer vision and performs automated actions through HID (Human Interface Device) commands without requiring direct system access.

Key Features

  • Visual screen observation and analysis
  • Autonomous task automation
  • No direct system access required
  • Human-like interaction patterns
  • Closed-loop feedback system

Research Domain

Literature Survey

Traditional UI automation tools such as Selenium and Appium rely heavily on DOM structures, APIs, or system-level access. While these tools are effective in controlled environments, they struggle in dynamic or black-box systems where internal structures are not accessible. Recent advancements in AI-based automation introduce vision-based approaches using computer vision and OCR to interpret UI elements.

However, most existing solutions lack real-time adaptability and fail to validate whether actions are successfully executed. Additionally, they depend on predefined scripts, making them fragile when UI changes occur.

Research Gap

Current automation systems lack a fully integrated closed-loop mechanism that combines perception, decision-making, execution, and validation. There is a significant gap in systems that can:

  • Operate without APIs or system-level access
  • Understand UI dynamically using visual input
  • Validate execution using real-time feedback
  • Adapt to unexpected UI changes automatically

Research Problem

Challenge: How can an intelligent system autonomously observe a screen, interpret user interface elements, execute actions, and verify outcomes in real-time without relying on system-level access or predefined scripts?

Research Objectives

🎯 Design & Decision Making

Design an Agentic AI system capable of autonomous decision-making

👁️ Vision Module

Develop a vision module to detect and interpret UI elements using OCR and image processing

⚙️ Actuation

Implement HID-based actuation for real-world interaction

🔄 Feedback Loop

Enable a closed-loop feedback mechanism for validation and error correction

🌐 Adaptability

Ensure adaptability to dynamic and unknown environments

Methodology - Closed-Loop Architecture

1

Perceive

Capture screen using a camera and extract UI elements using OCR

→
2

Plan

Generate action plans using a Large Language Model

→
3

Act

Execute actions using HID (keyboard/mouse emulation)

→
4

Evaluate

Re-capture the screen to verify if the action was successful

This loop continues until the task is successfully completed, enabling adaptive behavior.

Technologies Used

🐍 Python 🖼️ OpenCV 📝 Tesseract OCR 🧠 LLM (Mistral/LLaMA) ⌨️ ESP32 HID
